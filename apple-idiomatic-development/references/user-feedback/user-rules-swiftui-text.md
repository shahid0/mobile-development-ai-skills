# User Rules: Swiftui Text


## user-rule-swiftui-text-text-value-format-with-a-formatstyle-13baf3c08a

**Group:** swiftui-text
**Created:** 2026-05-29
**Updated:** 2026-05-29
**Guidance:** Use Text(value, format:) with a FormatStyle such as .number, .currency(code:), .percent, .measurement, or Date.FormatStyle attributedStyle when the deployment target supports it.
**Examples:** Display currency with Text(price, format: .currency(code: currencyCode)).
