# User Rules: Swiftui Layout


## user-rule-swiftui-layout-use-background-alignment-content-or-background-9f4a7ee06c

**Group:** swiftui-layout
**Created:** 2026-05-29
**Updated:** 2026-05-29
**Guidance:** Use .background(alignment:content:) or .background(content:) for decorative backgrounds that belong to one view.
**Examples:** Attach a decorative background with .background { BackgroundView() } on the decorated view.
